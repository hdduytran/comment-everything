# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). By participating you agree to uphold it.

In short: be respectful and constructive, welcome newcomers, accept feedback graciously, and do not harass or demean anyone. Unacceptable behavior includes harassment, personal attacks, publishing others' private information, and sexualized language or imagery.

## Scope and enforcement

This applies in all project spaces (issues, pull requests, discussions) and when representing the project in public.

Report unacceptable behavior privately to the maintainers using GitHub's private vulnerability and conduct reporting on this repository, or by contacting a maintainer listed in the repository directly. Maintainers will review every report promptly and fairly, respect the reporter's privacy, and may remove content or restrict participation as described in the Contributor Covenant's enforcement guidelines.

The full text, including the enforcement ladder (correction, warning, temporary ban, permanent ban), is at https://www.contributor-covenant.org/version/2/1/code_of_conduct/ and is incorporated here by reference. Contributor Covenant is licensed under CC BY 4.0.
